Crew banners

  crew-banner-*        README header, 1280x320 (and 2x)
  crew-social-*        GitHub social preview, 1280x640 (and 2x)
  crew-lockup-*        compact mark + wordmark, 640x160 (and 2x)

  transparent/         the same six, with no background painted

The files in this folder carry the #161826 ground. The ones in transparent/
have an alpha background: use them over any DARK surface. The wordmark, gloss
and subtitle are light (#e9e9ed / #a9abb8) and the opencode cell is off-white
(#fdfcfc), so on a light background the text and that one cell disappear --
on light surfaces use the dark-ground files, or ../crew-logo-mono.svg, which
takes the surrounding text colour.
